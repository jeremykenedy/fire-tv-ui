# Household reminders

Approved household reminder scope: local recurring chores, trash day and pet/plant reminders with timezone and completion controls.

Implemented one-time, daily and weekly local reminders with explicit label, date, whole-minute time and IANA zone. Each entry has a stable UUID, completion state and optional absolute snooze instant. Native controls support add/edit/delete, complete occurrence, snooze one actual hour and re-schedule completed one-time entries. Editing clears completion and snooze as stated in the editor. Daily/weekly completion advances to the first future occurrence, skipping missed dates while preserving the original local time and weekday cadence. Due and next are calculated from the selected zone, not the TV zone. DST gaps shift forward by the gap, overlaps use the earlier offset; the editor states these rules.

No background alarms, sounds, notifications, services, permissions, network access or TV wakeups are implemented. The editor and provider say so. The visible Home view refreshes every 30 seconds, reloads saved configuration on each refresh/start, and removes callbacks on stop/detach. Editor refresh changes status text without recreating controls or moving focus and stops on pause. No standby timing guarantee is claimed.

The provider is `widget.reminders.RemindersWidgetProvider`, stable key `widget:household-reminders`, default hidden. Model defaults additionally disable reminders until the user chooses Enable. Disabled retains all schedules but Home suppresses contents. Provider states are SETUP_REQUIRED when disabled, EMPTY when enabled without entries, READY with entries, UNAVAILABLE for unreadable retained data. Completed entries remain visible until deleted.

`widget.reminders.RemindersActivity` needs nonexported manifest registration by coordinator. Layout owner owns provider registration. No shared manifest/Main/Settings/build/backup or notes files were changed by this lane.

Storage is independent of notes: `native_household_reminders` / one String `document`. It has a strict bounded JSON schema and exact scalar types, duplicate IDs/keys rejected, 64 reminders, 128 label characters, date years 2020 through 2100, known IANA zones, and whole-minute local times. Unreadable data is kept; failed commits attempt restoration of the previous document including in-memory state. Beyond the supported date range, schedule edits/advances are rejected rather than silently wrapped.

Privacy defaults: Home counts only, portable exports excluded. Enabling label previews or allowing portable content requires a specific warning and user action. Anyone using this launcher can still open the editor. `RemindersPreferences.exportAllowed(Context)` and `portableDocument(Context)` expose consent-gated portable content; no exporter is added here. Backup integration must opt in explicitly and should reset imported export consent to false and Home summaries to true, or retain current local privacy settings. A file must not grant future consent.
