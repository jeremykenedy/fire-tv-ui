# Fire TV UI 1.5.0

Fire TV UI 1.5.0 makes featured-card sources visible and refreshable, preserves the actual source subtitle, and contains card artwork without cropping it. The screensaver catalog also pins the published Jellyfish Drift 2.0 filmed release and uses its real Deep ocean preview.

## Upgrade guide

Replace an existing production-signed 1.x installation without clearing app data. Use Toolkit's authenticated private UI handoff and **Advanced > Updates**, or the existing computer installer for older builds without that route. Android still confirms installation. Verify the APK against its SHA-256 sidecar. The repository and release APK remain private; no GitHub credential is sent to the TV.

No preference reset, migration, dependency installation, or cache clearing is required. Android 8.1/API 27, the package, and the production signer remain unchanged. Accepted layout, custom artwork, timers, Home behavior and screensaver selection are retained. Check the Cards source page, Main and the selected screensaver after upgrading.

Jellyfish 2.0 is a separate user-initiated screensaver update. Its native Settings exposes scene, playback speed, and random scene/speed selection. Six raw preference values remain stored; legacy density, species, and light rays have no effect on filmed scenes. See the tagged screensaver integration/configuration guide before using an external editor.

## Breaking changes

None in Fire TV UI. Existing settings keys and defaults are unchanged. Jellyfish 2.0 changes its visual renderer to filmed scenes; inactive legacy controls remain stored in that separate app and are not changed by this UI update.

## Major changes

**Preferences > Appearance > Cards > Card sources and refresh** shows real app-published feed counts, readable source names, read failures and actionable empty-source guidance. Refresh and reload are explicit. Available content is never invented when a source is empty.

The catalog updates Jellyfish Drift to the published 2.0.0/code 4 APK. Its real NOAA Deep ocean capture replaces the old synthetic preview. The exact media notice is available offline under **Advanced > Preview media credits**.

## Minor changes and fixes

- Preserve each preview card's source subtitle while keeping its existing inclusion behavior.
- Add bidirectional remote focus between Cards text color and the new source row.
- Fit featured artwork within its card; app icons and other image surfaces are unchanged.
- Preserve all accepted launcher layout/default values and installed screensaver preferences.

## Security and data integrity

Catalog download size, SHA-256, package, and production signer checks remain required. No new permission, account connection, background service, or personal Plex pairing code is included. Personal Plex integration remains separate unpublished work.

## Verification

Local checks and current-build native/release screenshots are required before publication. Native gates for this exact code 43 candidate remain pending during preparation. Prior isolated native proof established source-label preservation, wide/portrait artwork containment, and D-pad access to the Sources page; it is not a substitute for the final release gate. Third-party checker work remains deferred at the user's request.

## Limits and rollback

A compatible installed producer must publish cards. Prime/Netflix/Amazon recommendations are not automatically imported from Amazon Home, and personal Plex library linking is not part of this release. Home behavior limitations are unchanged. Jellyfish's video sources contain fixed recorded subjects and edited loops; this host pin does not claim user visual acceptance or native 4K output.

Android prevents an in-place downgrade to a lower version code. Save a backup before any intentional uninstall; uninstalling clears the UI's private app data. Independently installed apps remain installed.
