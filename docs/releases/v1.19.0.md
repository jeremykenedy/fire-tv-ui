# Fire TV UI 1.19.0

1.19.0 adds whole-show Plex hiding and more control over the existing production interface. It retains the original app, artwork, layout and saved choices. The independent replacement is not part of this release.

## Upgrade guide

The direct upgrade source is stable 1.18.1/code 81. This update uses the same production package and certificate with version code 82. Android API 27 remains the minimum. Save a launcher backup and retain selected personal media before updating.

Use **Settings > Updates > Check for updates** and confirm the Android replacement, or verify the downloaded checksum and install in place:

```sh
shasum -a 256 -c fire-tv-ui-1.19.0.apk.sha256
adb -s YOUR_TV_IP:5555 install -r fire-tv-ui-1.19.0.apk
```

No new permissions, accounts, dependencies, migration or preference reset are required. Do not uninstall to bypass a signature or version error; uninstalling deletes private data. Earlier 1.x paths remain documented in their release guides. The separate preview is not an upgrade source.

After updating, open a personal Plex show or episode and choose **Hide entire show**. Confirm that other shows remain available. Restore the show from **Cards > Featured card setup > Hidden cards**; individually hidden episodes remain hidden.

Android normally blocks downgrading code 82 to code 81. Preserve the installation for a corrective update. A preference backup does not downgrade the APK or restore credentials and external media.

## Breaking changes

None. Existing appearance choices, app actions and platform requirements are retained. App focus defaults to Fast (120 ms); choose Normal (180 ms) to retain the previous focus duration. Saved growth and shadow values are unchanged.

## Major changes

**Hide entire show** uses the Plex server and series identity to hide a show and its episodes, including episodes published later. Existing published episodes are verified before saving the rule. When verification is unavailable, individual hiding remains available. Hidden cards keeps the show's name even when its feed is unavailable, and restoring a show preserves individual episode hides. Other providers retain their individual-title controls.

**App Icons > App hover and focus** keeps the growth and shadow controls together and adds Fast (Default), Normal and Slow focus speed. Focused border opacity offers Default (90%), Off, 25%, 50%, 75% and 100%, independently of growth, shadow and fill. The same controls remain in Layout and focus. They apply to apps on Home and in folders, and are included in backups and saved setups.

**Change Icon** now opens a curated picker containing the original 48 HD logos. Brand categories, available installed icon packs and explicit personal-image browsing keep unrelated screenshots and downloads out of the default catalog. Factory and theme resets remain available, and existing custom images are preserved.

**Featured card setup > Channel card size** adds Default, Compact, Standard, Large and custom dimensions. The default keeps the existing card layout. Widget sizing, artwork Fit/Fill, titles and timers remain independent. Card size is included in backups and saved setups.

## Minor changes and fixes

The maintenance builder retains the historical 1.18.1, 1.18.0 and 1.17.1 recipes. The default independent builder is unchanged.

## Verification and limits

The complete maintenance host suite passed: 87 tests ran, with six existing opt-in device checks skipped. The standalone Java checks passed, and three recipe checks verified current and historical source reconstruction and rejected altered inputs. Compared with public 1.18.1, all 702 unchanged runtime entries and all 48 original HD logos match byte for byte. Only the manifest, typed preference catalog and two DEX files differ.

The exact production-signed APK was installed over public 1.18.1 on owned Android TV API 34 emulators. Native focus checks covered the actual App Icons route, existing 30% growth and Large shadow, Fast/Slow selection, border opacity, restart persistence and repeated direction changes. Eleven scoped preference fields and the separately recorded platform settings matched through that upgrade; this is not a claim that every private file remained byte-identical during normal application use.

Native card checks preserved the two sample feeds and their Manual/inherited timers through the upgrade. Compact, Large and maximum custom sizing rendered correctly, survived process restart and kept the app row reachable. Returning to Default reproduced the full two-card area from public 1.18.1 pixel for pixel. Cards Off collapsed the unused region; widget geometry remained independent. Whole-show hiding covered existing and newly published episodes, preserved an unrelated series and movie, and restored the named show without clearing an individual hide.

The curated picker retained every captured baseline preference key, value and Android runtime type, along with the original selected custom-image bytes. Actual catalog selection, readable saved-setup and backup restoration, and the existing icon-pack choice passed on the signed update. The 48 original HD logos are unchanged. Earlier scoped native checks also covered installed-pack failure recovery, larger text and personal-image paging.

The [current screenshot gallery](../screenshots.md#current-stable-interface) contains unmodified captures from this exact APK. The API 34 tests do not establish physical remote latency or acceptance on every Fire TV model.

Home routing, soundbar control and external Plex playback/resume retain their existing limits. The independent replacement remains separate.
