# Fire TV UI 1.2.0

Fire TV UI 1.2.0 adds 32 HD app and input icons, fixes physical input selection on Fire TV televisions, and closes app context menus when returning Home. The README television now has three scrolling rows at different speeds.

## Upgrade guide

Install the signed `fire-tv-ui-1.2.0.apk` over any existing 1.x installation with the same signing key. Android 8.1 / API 27 remains the minimum. No reset, migration, or configuration changes are required. Saved layouts, icons, screensaver selection, and timers are preserved.

From a checkout of this release, install the APK, permissions, Home routing, and icons together:

```bash
python3 scripts/install.py --serial YOUR_TV_IP:5555
```

If installing the APK separately, also install the icon pack:

```bash
python3 scripts/install_icons.py --serial YOUR_TV_IP:5555
```

The release includes a separate `fire-tv-ui-icons-1.2.0.zip` and SHA-256 sidecars. Verify downloaded files against those sidecars. Images live in shared `Pictures/Icons`; close and reopen an existing picker after installation. Long press an app or input, choose **Change Icon**, then select the logo. Re-select an existing custom icon to replace the launcher's stored copy with this release's caption-free artwork.

Check each configured input and press Home with a long-press menu open after upgrading. See the [icon guide](https://github.com/jeremykenedy/fire-tv-ui/blob/v1.2.0/docs/icons.md) and [installation guide](https://github.com/jeremykenedy/fire-tv-ui/blob/v1.2.0/docs/installation.md).

## Breaking changes

None. Package identity, signing key, runtime minimum, and configuration defaults are unchanged.

## Major changes

- Add 32 centered, proportion-preserving 1920x1080 logos covering Nintendo, Sega, PlayStation, Xbox, DVD, VCR, Blu-ray, LaserDisc, stereo receivers, Meta VR, Meta Quest, MacBook, laptop, and PC. There are no separate text captions.
- Install and publish the images to Android's media library automatically. Both Fire TV UI and LTvLauncher's app-banner picker can use the shared images.
- Switch physical Fire TV inputs through the system input-switch service. HDMI and Composite tiles open their matching ports instead of Live TV settings. Unsupported devices retain Android's standard input route.

## Minor changes and fixes

- Reset transient launcher views on Home, including app context menus whose local state survived the earlier Settings reset.
- Animate the README television's top and bottom rows left and middle row right, with 8-, 14-, and 11-second loops. Include separate light/dark still images for reduced motion.
- Include vector sources, provenance, regeneration instructions, and a separate icon ZIP in build output.

## Verification

See [device and build verification](https://github.com/jeremykenedy/fire-tv-ui/blob/v1.2.0/docs/verification.md) for completed checks and platform limits.

## Security and data integrity

No new permissions, network services, tracking, or analytics. Input switching uses the installed system service and retains its parental-control handling. Installation keeps existing preferences and explicitly publishes only the catalog's media entries.

## Rollback

Back up launcher settings before uninstalling. Android blocks installing a lower version code over this release. To return to 1.1.3, uninstall 1.2.0, install the signed 1.1.3 APK, then restore the backup. The shared icon files can remain on the TV.

## Known limitations

Physical input verification covers AFTDEC012E on Fire OS / Android 11. Other television models, physical Android TV, and physical Google TV were not tested for this release. LTvLauncher's app banners accept custom images; its built-in input panel does not expose that control. Brand logos remain the property of their owners.
