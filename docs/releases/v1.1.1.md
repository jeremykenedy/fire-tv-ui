# Fire TV UI 1.1.1

Fire TV UI 1.1.1 separates the regular TV sleep timer from Deep Sleep controls. The timers page now offers a native TV Sleep Timer, the screensaver delay, a Deep Sleep toggle, and a separate Deep Sleep timer. The app icon has also been refreshed.

## Upgrade guide

Install the signed `fire-tv-ui-1.1.1.apk` from this release over version 1.1.0. The update uses the same signing key and preserves the existing app profile. No settings migration is required. The published SHA-256 file is `fire-tv-ui-1.1.1.apk.sha256`.

The Fire TV Toolkit can install the APK and verify its published checksum:

```bash
firetv-ui --install --apk=/path/to/fire-tv-ui-1.1.1.apk --sha256=PUBLISHED_SHA256
```

## Minor changes

- Added a native TV Sleep Timer control, separate from Deep Sleep.
- Added an independent Deep Sleep toggle and Deep Sleep timer.
- Added and documented the Fire TV Deep Sleep setting behavior.
- Refreshed the app icon and captured updated Android TV emulator screenshots.

## Verification

- `bash scripts/test.sh`: 33 Java checks and 8 Python tests passed. One screensaver route test was skipped because its optional emulator serial was not supplied.
- `python3 scripts/build.py`: signed version-code-30 APK built and verified for v2/v3 signature and alignment.
- The signed APK was installed on an Android TV emulator running Android 12 / API 31. The regular `sleep_timeout` value was set to 60,000 ms and 0, then restored to 1,200,000 ms. The timer interface and updated About screen were visually checked at 1920x1080.
- APK SHA-256: `466dbd52d282746a484f4db45e6e2496383f3fb71c40aff145f55aabc0269775`.
- No physical TV was tested. In particular, the emulator does not verify Fire OS Deep Sleep or Alexa behavior. A Fire TV device tester is needed for those checks.

## Security and privacy

This release adds no analytics or tracking. Deep Sleep controls use local device settings.

## Rollback

Android does not permit installing the lower version code over this release. To return to 1.1.0, back up the app settings, uninstall 1.1.1, install the signed 1.1.0 APK, and restore the settings.
