# Fire TV UI Source Preview 2.0.0-alpha.2

This prerelease updates the separately installed native preview. Stable Fire TV UI 1.17.0 remains the stable release, and the preview does not replace the TV's Home app or automatically import production settings.

## Upgrade guide

The preview requires Android 8.1 / API 27 or newer. Download the source-preview APK and checksum from the alpha.2 release and verify the checksum before installing. A preview signed with a different key cannot be updated in place. Export supported preview settings and retain personal files before updating or removing an earlier preview; data continuity from a nonempty earlier preview has not been qualified. Android may require installation approval.

Production 1.x uses a separate package and data. Leave it installed to keep its configuration. To stop using the preview, return to the TV's existing Home; uninstalling the preview deletes its private data. A preview backup does not include account credentials or restore Android file permissions.

## Breaking changes

The preview remains a separate application. There is no automatic production upgrade or Home takeover. Supported device minimums remain Android 8.1 / API 27. Weather records that retain a city without exact coordinates require choosing the location once before an NWS forecast can load; the saved city and units are retained.

## Major changes

- **Tonight watchlist:** keep a local list, mark titles watched and look up exact Plex items when an authorized connection is configured. The list does not synchronize watch history across services.
- **On This Day:** view a dated event from Wikipedia with contributor, source and license attribution. It requires internet access.
- **Holiday appearance:** choose the included holiday scenes and coordinated icon colors, and restore saved presentation setups.
- **Plex profiles:** available profiles can remain usable when another profile fails to load. Plex features require an authorized connection and supported server data.

New widgets start hidden. Enable and configure them in Home layout. Weather coverage, recommendations and external links depend on their providers and the TV's available handlers.

## Minor changes and fixes

The preview includes the native focus, layout and settings improvements in this source release. Unavailable providers and unsupported settings remain visible as limitations rather than being silently converted.

## Verification and limits

The source preview is built from the maintained native Java and resources and uses the established preview signing identity. The signed alpha.2 candidate was opened on an Android TV API 34 emulator; Home, Settings and Widgets were visible, and the temporary app state was restored afterward. Earlier feature-specific native checks cover the watchlist and history widget. This does not qualify the final release APK until its source and payload are checked against the candidate. Emulator checks do not establish physical Fire TV, remote Home, voice, CEC or receiver behavior. Production migration and complete 1.x parity remain outside this preview.

See the [preview guide](../source-preview.md) for installation, screenshots and data boundaries. Compare [alpha.1 with alpha.2](https://github.com/jeremykenedy/fire-tv-ui/compare/v2.0.0-alpha.1...v2.0.0-alpha.2).
