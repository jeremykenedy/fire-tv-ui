# Fire TV UI Source Preview 2.0.0-alpha.2

This prerelease updates the separate native preview with the restored Home tray and Settings side panel. Stable Fire TV UI 1.17.0 remains the latest stable release. The preview does not replace the TV's Home app or automatically import production settings, and this release does not claim complete 1.x parity.

## Upgrade guide

The declared minimum remains Android 8.1 / API 27. Alpha.2 uses package `com.jeremykenedy.firetv.ui.preview`, version code 3 and the maintained preview certificate `c64ca640cab78e75fd52a6bb43bcbf145aa1b951f0c719b471df241bf70669c6`. Download only the versioned source-preview APK, checksum and `release-artifact.json` from the published release. Verify the checksum before installation.

```sh
shasum -a 256 -c fire-tv-ui-source-preview-2.0.0-alpha.2.apk.sha256
```

Public alpha.1 uses the same certificate and a lower version code. A guarded API 34 in-place update preserved six populated grid and focus choices without uninstalling or clearing data. This is a bounded synthetic upgrade check, not a guarantee for every owner setting. Preserve supported preview exports and selected personal files before updating. A local review build may use a different signer. Do not uninstall it simply to bypass a signer mismatch, because uninstalling deletes its private data.

Production 1.x uses a separate package and data. Leave it installed to retain its configuration. Preview exports do not include account credentials or restore Android file permissions. No production migration, Home routing change, dependency installation or reboot is part of this preview upgrade. To stop using the preview, return to the existing Home app. Removing the preview deletes its own local data; no production downgrade is needed.

## Breaking changes

The preview remains a separate application with no automatic production upgrade or Home takeover. Minimum API 27, target API 36, disabled automatic app-data backup and the maintained preview signer are unchanged. Home and Settings navigation is reorganized: use **Settings > UI settings** for Apps, App Icons, Widgets and Cards, and **Theme and wallpaper** for appearance choices.

Weather records containing only a city still require choosing an exact location before an NWS forecast can load; the saved city and units are retained. Optional providers, account connections and selected personal files require explicit configuration. Card settings now include package-wide hidden sources; older native card snapshots remain readable.

## Major changes

- **Home and Settings:** the native Home tray and Settings side panel restore the existing navigation structure, with focus presentation, remote navigation and panel transitions handled by maintained native code.
- **Apps and cards:** the Apps manager provides staged app visibility and package-wide Hide Cards choices. Hiding a package also covers cards it publishes later, while retaining feed order, timers and individual title choices. Cards controls include featured-card visibility, title visibility and text placement.
- **App Icons and wallpaper:** App Icons restores radius, shadow, focus colors and the compact favorites dock, while Theme and wallpaper groups light/dark backgrounds, selected images or video, image URLs, icon packs, backgrounds/overlays and saved setups. Subreddit wallpaper remains paused; its saved choice is retained.
- **Local widgets and appearance:** Tonight keeps a local watchlist with exact Plex lookup through an authorized connection; On This Day shows a dated Wikipedia event with attribution. Holiday presets coordinate appearance and optional icon colors with interrupted-change recovery. These features do not synchronize streaming-service watch history. New widgets start hidden.

## Minor changes and fixes

- Favorites supports bottom placement, hidden or colored backing and static wallpaper blur. Image loading refreshes the blurred dock when the image becomes available. Video and system-wallpaper blur remain unqualified.
- Nested Settings panels keep Home visible beneath the active menu. The wide background editor keeps focused row labels within its bounds.

- Saved grid column choices through 20 are retained rather than clamped to a narrower range, with tile sizing that fits the available width.
- Saved setups and portable presentation state retain package card visibility alongside supported existing choices. Credentials, lock secrets and device control state keep their separate boundaries.
- Available Plex profiles can remain usable when another profile fails. A partial source result is not reported as complete availability.
- Settings and presentation editors retain startup/recovery gates, and unsupported legacy values remain explicit rather than silently reset.

## Security and data integrity

The preview registers no production Home or accessibility service and keeps its own application data. General cleartext HTTP remains disabled. Tonight's external links and exact Plex actions use available handlers and launcher lock checks; Plex also requires an authorized connection. These actions do not establish entitlement or universal exact-title playback.

Package card choices use the shared presentation monitor and recovery gates. Supported snapshots retain those choices, and invalid imports are rejected before application. These checks do not establish a production migration guarantee.

- The versioned, signed API 34 candidate matches all 455 recorded build inputs at `c5bc6b56e32f7afe73c0eefe04427e9bec68b542`. Its SHA-256 is `c2986cd5d0e5b72ec357a5f3b2fe5b4a07e868feb132fe1c15bf5cf37c8b4309`; the [screenshot record](../../art/screenshots/source-alpha2-provenance.json) identifies each unmodified native capture.
- Native checks covered Home focus and D-pad navigation, nested panels, wallpaper choices, App Manager saving and icon routes, mini dock navigation, widget toggles, color pickers, Advanced focus and Remote controls. The native review caught and corrected black menu underlays and clipped background-editor labels.
- The 52 host suites, three device routing policies, production contracts, installer checks and build checks passed. Clean preview and production builds run in the required GitHub workflows. The final release's `release-artifact.json` identifies its clean primary-branch source, signer, SDK configuration, source hashes and APK checksum.
- The guarded alpha.1 upgrade check preserved six populated grid/focus settings through an in-place update and Home/Settings navigation. Full guard restoration and baseline verification completed. This does not prove migration of production accounts, personal media or every existing preference.

API 27 runtime coverage, production migration and complete 1.x parity remain separate qualification work. No physical voice, remote Home, CEC or receiver acceptance is claimed. Provider permissions, published data, authorized connections and available handlers determine content availability. External service additions remain deferred.
