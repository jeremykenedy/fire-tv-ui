# Fire TV UI 1.6.0

Featured card setup now combines source controls, individual card hiding, app recommendations and personal Plex feeds. Existing launcher layout, custom icons, Home routing and device settings are preserved.

## Upgrade guide

Replace Fire TV UI 1.4.1 or a later private preview with the production signed 1.6.0 APK. Do not uninstall or clear data. Use Toolkit's authenticated private update handoff, then confirm installation in Advanced > Updates. Existing installations already on the current version need no replacement.

After updating, open Preferences > Appearance > Cards > Featured card setup. Enable optional sources deliberately. App recommendations require notification access through Android settings. A personal Plex connection requires approval of the displayed link code. Neither credential nor notification access is transferred by launcher backups.

No database migration, account reset or launcher layout reset is required. Save a portable backup before changing preferences. Older APKs with lower Android version codes cannot replace this release without a destructive uninstall, so preserve data and use a newer corrective release for rollback needs.

## Breaking changes

None for existing launcher settings. Source access remains optional. The original Jellyfish Drift and the separate filmed Jellyfish Drift V2 use distinct packages and retain separate preferences.

## Major changes

* Featured card setup has a visible first entry in Cards settings.
* Channel Manager can hide or restore individual programs while retaining the channel and its other cards.
* App recommendation notifications can supply real cards and their original actions with explicit access approval.
* Personal Plex supports authorized Continue Watching, separate new movie and episode feeds, and optional user filtered activity feeds.

See [Featured cards](../featured-cards.md) for setup, privacy and availability limits.

## Minor changes and fixes

* Source labels preserve their producer rather than calling every preview Watch Next.
* Fit and Fill apply only to featured artwork.
* Big picture artwork supports manual or timed changes.
* Removing recommendation access clears its cards without a listener lifecycle crash.
* Android 14 recommendation actions use the public PendingIntent sender option while retaining the exact original action.
* Published screensaver pins and previews track the separately verified release contracts.

## Security and data integrity

Plex device credentials stay encrypted and outside portable backups. Requests validate the selected server identity. Recommendation actions stay in memory and are checked against current notifications before dispatch. The listener ignores unrelated apps and notification categories. Hidden card identities contain hashes rather than raw playback intents or credentials.

## Verification and limits

Functional local tests and signed builds cover the changed card and Plex behavior. Native checks distinguish completed rendering, hiding and listener lifecycle checks from pending item playback interoperability. Card availability depends on each producer and the authorized server. Another user's Continue Watching is not inferred from watch history. A Plex profile picker is not proof of selected item playback.

Hardware Home behavior from intentional Amazon Home remains a separate physical remote check. No claim is made that every requested app publishes cards on Fire OS.
