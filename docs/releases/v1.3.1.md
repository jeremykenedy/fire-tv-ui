# Fire TV UI 1.3.1

Fire TV UI 1.3.1 updates the Rainforest Cascade catalog download to its signed 1.1.0 release and replaces the older preview with its garden waterfall captured on physical Fire TV.

## Upgrade guide

Install the signed `fire-tv-ui-1.3.1.apk` over an existing 1.x installation. Android 8.1 / API 27 remains the minimum. The existing signing key, package identity, layouts, icons, selected screensaver and timer settings are preserved. No migration or reset is required.

Verify the APK against its published SHA-256 sidecar. Open **Settings > Screensavers > Install screensavers** to install or update Rainforest Cascade. The catalog does not select a screensaver automatically.

## Breaking changes

None.

## Major changes

None. This is a catalog and preview patch.

## Minor changes and fixes

- Pin Rainforest Cascade v1.1.0 to the independently downloaded 72,053,957-byte APK with SHA-256 `88602f840deae1e9a7fa8de5b1dda03601c70d0d70399ab11262e1817e7de31f`.
- Refresh the bundled garden preview and record its physical Fire TV source and image hashes.
- Preserve all 30 catalog entries and existing native launcher behavior.

## Security and data integrity

The catalog retains HTTPS, exact byte-count and SHA-256 verification, and Android package identity checks. Rainforest Cascade retains its existing package and release signer. This patch adds no permissions or network services.

## Rollback

Android blocks installing a lower version code over this release. Save a TV backup before uninstalling, then install the previous signed APK and restore the backup. Screensaver apps remain installed independently of Fire TV UI.

## Known limitations

The Rainforest capture documents the installed screensaver's physical output. It does not establish physical launcher verification for this patch. Other unreleased screensaver candidates are not added by this update.
