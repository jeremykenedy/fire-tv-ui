# Fire TV UI 1.10.1

Refresh the existing Hearth Presence and Prism Clock catalog entries and native
previews. Launcher code, card behavior, animated backgrounds, app layout,
selected screensaver and timer defaults are unchanged.

## Upgrade guide

Update 1.10.0 in place through Settings > Advanced > Updates, or verify the signed
published APK and use the existing computer installer:

```sh
shasum -a 256 -c fire-tv-ui-1.10.1.apk.sha256
python3 scripts/install.py --serial YOUR_TV_IP:5555 --apk /path/to/fire-tv-ui-1.10.1.apk
```

Older same-signer versions can use that installer too. Do not uninstall, clear
app data, reboot the TV or reset accounts. Existing layout, custom icons, cards,
orders, device-local encrypted Plex connections and permissions remain in place.
Android 8.1/API 27 and the production signer are unchanged.

A host update does not automatically replace or select a screensaver. Use the
catalog or existing installed-app update controls for an explicit replacement.
Hearth keeps all eleven settings keys; its existing flame-size choice now also
controls wood height above fixed logs. Prism's Show clock defaults On and cannot
be randomized, preserving prior behavior unless explicitly turned Off.

## Breaking changes

None. Both app identities, selected defaults, host runtime, saved preferences
and other catalog entries are preserved. The catalog remains 34 entries.

## Major changes

No new launcher runtime feature. Screensaver options continue to open the app's
own exported settings; this update does not add a generic settings editor.

## Minor changes and fixes

- Pin the existing Hearth and Prism entries to their verified public 1.1.0 APKs.
- Replace their bundled samples with current, unretouched physical native output.
- Record Hearth's eleven settings and Prism's twelve-row schema, with Show clock
  as a boolean/default true/nonrandom control.
- Include Hearth's tagged media notice and complete CC BY 3.0 attribution in the
  existing offline Preview media credits reader.
- Include Prism's original Apache 2.0 notice and full license in the same reader.

## Security and data integrity

No new permission, library, tracking, network destination or background service
is introduced. Existing checksum/package verification and Android installation
confirmation remain in use. The host update preserves device-local credentials,
remote identities and all existing appearance/feed preferences.

## Verification and known limits

The signed build passed 46 local tests and nineteen built-artifact checks; six
device-only tests are explicitly skipped by the local suite. Both DEX files
match public 1.10.0 byte for byte. The API 34 native gate passed the current
picker, both app-owned settings routes, visible Hearth Preview, Prism clock
On/Off previews, Back and offline credits scrolling. Fresh UI14/OS19, providers,
external files, appops and actual accessibility/guard state were preserved. Screensaver scenes
and controls belong to their apps. A Preview activity is not a system Dream,
and emulator results do not establish physical performance. Newly filmed modern
gas, audible crackle quality and long-duration thermal evidence remain open.
Prism retains its original renderer, including the measured physical API 28
default of about 17–18 presents per second. This patch does not claim a GPU
improvement. Automatic external Plex playback and saved-offset resume are not changed or
claimed complete by this catalog patch.

Keep a backup before deliberate recovery. Android normally rejects a lower
version-code replacement; use a newer signed repair build rather than removing
an installation and its encrypted connections.
