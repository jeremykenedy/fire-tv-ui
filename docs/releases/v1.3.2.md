# Fire TV UI 1.3.2

Fire TV UI 1.3.2 fixes impossible installed-app storage figures returned by some Fire TV firmware. An installed app's reported size must cover its actual base and split APK files before the UI displays the platform's usage totals.

## Upgrade guide

Install the signed `fire-tv-ui-1.3.2.apk` over an existing 1.x installation after verifying its SHA-256 sidecar. Android 8.1 / API 27 remains the minimum. Package identity, signing key, layouts, icons, screensaver selection and timer settings are preserved. No migration or reset is required.

Open **Settings > Screensavers** or **Install screensavers** to read the corrected usage description. When platform figures are inconsistent or restricted, the UI shows measured **App files** and explicitly marks data/cache statistics unavailable. App files are not presented as total installed storage or download size.

## Breaking changes

None.

## Major changes

None. This is a storage reporting correction.

## Minor changes and fixes

- Reject app storage figures smaller than the measured installed base and split APK files.
- Reject negative counters, cache larger than data, and overflowing totals.
- Count cache within data once, as Android specifies.
- Keep unavailable statistics explicit and preserve the verified 30-entry screensaver catalog.

## Security and data integrity

This patch adds no permissions, network services, setting changes or storage repair actions. Storage inspection remains read-only.

## Rollback

Android blocks installing a lower version code over this release. Save a TV backup before uninstalling, then install the previous signed APK and restore the backup. Screensaver apps remain installed independently of Fire TV UI.

## Known limitations

Restricted data/cache statistics cannot be recovered from APK file sizes. The UI reports them as unavailable rather than guessing.
