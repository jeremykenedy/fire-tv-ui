# Fire TV UI 1.10.0

Release preparation for fixed featured feeds, unified screensaver controls and optional animated menu backgrounds. This candidate is not yet published.

## Upgrade guide

Update an existing signed Fire TV UI installation in place. From 1.9.2 or earlier versions using the same production signer, check Settings > Advanced > Updates and confirm the published replacement in Android's installer once this release is available. The computer installer is an alternative:

```bash
python3 scripts/install.py --serial YOUR_TV_IP:5555 --apk /path/to/fire-tv-ui-1.10.0.apk
```

Do not uninstall or clear app data. Existing appearance, feed visibility, hidden items, item order, top-level feed order and authorized Plex connections remain in place. No new account, permission or dependency is needed for the menu effects. Animation starts Off; choose Settings > Animated backgrounds to opt in.

Use Settings > Screensavers for selection, enabled state and timers. Appearance > Screensavers opens that same page. An older private launcher switch no longer competes with the system controls.

After updating, check the current screensaver and timers, open a featured card menu and confirm its title matches the card, and review the optional background settings. Keep a local launcher backup before any manual recovery. Android prevents ordinary installation of lower version codes; do not uninstall a working installation just to roll back, because that would remove device-local encrypted connections. Use a newer signed repair build if needed.

## Breaking changes

The Android 8.1/API 27 floor and signing identity are unchanged. Featured titles now rotate inside fixed feed cards rather than automatically moving the entire strip. Manual keeps the current child. The same saved interval remains in use; visibility and ordering do not require migration.

The separate launcher screensaver switch is replaced by a route to the dedicated system controls. Existing legacy values remain stored but no longer enable or disable a competing launcher mode.

## Major changes

- Each app or logical channel retains one stable card. Its visible ordered titles change internally, with the current child preserved across refresh when still available.
- Current-item menus hold their selected title while open. Hiding or reordering an item does not target a later rotated child.
- Quiet particles, Aurora ribbons, Connected lights and Prism light provide opt-in native Main backgrounds, with speed, intensity and brightness controls. Leaving Main stops the animation. Off restores the existing wallpaper behavior.
- Screensaver setup has one authoritative area for enabled state, selection and timers.

## Minor changes and fixes

- Cold-start and resumed Main start the card clock and selected background independently of the asynchronously created launcher model.
- Stable logical-feed lookup handles copied launcher card objects without falling back to a stale first title.
- The Plex item panel retains validated Open/details and saved progress, while removing the unsupported automatic Resume action.

## Security and data integrity

No additional permissions, tracking or network dependency is introduced. Existing encrypted Plex credentials remain device-local. Safe emulator fixtures contain no real server or account connection and are removed after validation. Item visibility and ordering remain portable preferences; publisher content and watch history are not deleted.

## Verification and remaining limits

The signed code 66 candidate passed the local 51-test run with 45 passes and six device-only skips. API 34 emulator checks verified fixed card bounds and focus, coherent title/art changes, the exact safe current-item action, five-second rotation, Manual, paused menu snapshots, hide/restore, item ordering and top-level feed ordering. All four animated styles rendered on Main, stopped after leaving Main and resumed from a cold app start. Off returned to the default wallpaper. Strict cleanup restored the recorded UI, OS, provider, package, external-file, app-op and accessibility state.

The remaining interval choices and source visibility were not repeated in that native run. Physical-device checks for this candidate are pending. Emulator animation checks do not establish physical TV frame rate. Automatic external Plex playback or offset resume remains unverified; opening Plex or its profile picker is not playback proof.
