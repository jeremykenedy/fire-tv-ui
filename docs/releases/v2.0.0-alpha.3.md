# Fire TV UI Source Preview 2.0.0-alpha.3

This prerelease fixes widget groups in named saved setups. It retains the existing Home and Settings presentation in the independently maintained native preview. Stable Fire TV UI 1.17.0 remains the latest stable release.

## Upgrade guide

Install the versioned APK over public alpha.1 or alpha.2 with `adb install -r`; do not uninstall or clear application data. Alpha.3 uses package `com.jeremykenedy.firetv.ui.preview`, version code 4 and the maintained certificate `c64ca640cab78e75fd52a6bb43bcbf145aa1b951f0c719b471df241bf70669c6`. Android 8.1 / API 27 remains the declared minimum, with target API 36.

Download the APK, checksum and `release-artifact.json` from this release, then verify and install:

```sh
shasum -a 256 -c fire-tv-ui-source-preview-2.0.0-alpha.3.apk.sha256
adb -s YOUR_TV_SERIAL install -r fire-tv-ui-source-preview-2.0.0-alpha.3.apk
```

A guarded API 34 alpha.2 upgrade retained synthetic widget groups, six grid/focus choices and an existing named setup. Applying the older setup preserved the groups; creating and applying a new alpha.3 setup restored its captured groups. This bounded check does not establish preservation of every owner setting or account. Public alpha.1 shares the identity and has a lower version code, but the alpha.1-to-alpha.3 path was not separately exercised.

Keep stable Fire TV UI installed. The preview has separate data and does not replace the Home app or import production accounts. No dependency commands, cache resets, production migration or reboot are required. Preserve supported preview exports and personal source files. If Android rejects a differently signed local review build, do not uninstall it just to bypass that rejection.

To stop using the preview, return to the existing Home app. Uninstalling deletes the preview's local data; no production downgrade is needed. New setup files are not promised to be usable by older preview versions.

## Breaking changes

No change to the preview package, SDK floors, signer, Home registration or default presentation. New named setups record their native snapshot version. Older setups remain readable and preserve widget groups they never captured; new setups can restore either captured groups or their absence.

## Major changes

Named saved setups now retain exact widget group JSON, including group order, widget IDs and configuration. Applying an older setup no longer removes current groups merely because those groups were absent from the older format.

## Minor changes and fixes

- Production-source preflight recognizes verified typed icon radius/shadow, compact dock, blur, dock position, Back override and icon background choices already consumed by the native UI.
- Supported disabled Clock/Year group records retain their original JSON and content mode through the migration journal. Unsupported groups and enabled-widget migrations still stop before changing saved data.
- A saved Appstore-blocking option can migrate when the update-blocking master is false or absent. Enabled legacy VPN protection remains gated.
- Portable exports leave widget groups on this TV. Older backup imports preserve local groups; nested group data in portable imports is rejected. Existing restrictions on unsupported legacy nested settings still apply.
- Widget edits share the setup transaction lock and stop while recovery is pending, so a successful edit cannot be silently overwritten by restoration.
- Unknown setup versions and malformed presentation settings are rejected before application.

These production-source improvements are not a production upgrade path in this separate preview package.

## Security and data integrity

The preview keeps its separate data and registers no production Home or accessibility service. Saved-setup changes use the existing recovery transaction. Unknown legacy settings and unsupported migration cases are retained instead of silently reset. Credentials, device controls and personal media retain their existing boundaries.

## Verification and limits

The focused migration, saved-setup, widget-group and update-block suites pass, including API 36 compilation and interrupted journal recovery. The combined source passed all 53 reviewed host suites and 34 production contract, installer and build checks. The saved-setup compatibility correction passed 195 focused checks and its native alpha.2 upgrade test.

Guarded API 34 production-package lab checks also passed disabled Clock/Year modes, explicit status Off, saved-setup restore, write-free Weather rejection and typed display settings after process restart. These used synthetic data and a lab signer, not a real 1.17 upgrade. Native backup checks passed the local group export/import boundary. Guarded app data and the recorded package, Home and accessibility baselines were restored.

The release artifact records the clean primary-branch source, SDK configuration, signer, source hashes and APK checksum. The [native screenshot record](../../art/screenshots/source-alpha3-provenance.json) identifies the captured candidate and unmodified images.

Production 1.x replacement remains incomplete. Enabled legacy VPN protection, unsupported group/content combinations and physical Home, voice, remote, CEC and receiver acceptance remain separate work. API 27 runtime coverage and every provider playback path are not established by API 34 emulator tests. External service additions remain deferred.
