# Fire TV UI 1.20.0

This update keeps the existing production interface and adds optional appearance choices. Settings returns to the selected app, and default widget text follows the visible background while retaining the selected opacity.

## Upgrade guide

The direct upgrade source is stable 1.19.0/code 82. The update retains the production package and signing certificate and advances to code 83. Android API 27 remains the minimum. Save a launcher backup and keep selected personal media available before updating.

Use **Settings > Updates > Check for updates** and confirm the Android replacement, or verify the downloaded checksum and install in place:

```sh
shasum -a 256 -c fire-tv-ui-1.20.0.apk.sha256
adb -s YOUR_TV_IP:5555 install -r fire-tv-ui-1.20.0.apk
```

No new accounts, permissions, dependencies or preference reset are required. Do not uninstall to bypass a signing or version error. The independent preview is not an upgrade source. Earlier 1.x paths remain in their release guides.

Android normally blocks downgrading code 83 to code 82. Keep the installation for a corrective update; a preference backup does not downgrade the APK or restore external media and credentials.

## Breaking changes

None. Existing appearance choices, artwork, card controls, focus growth and shadow remain. New backgrounds and presets are optional. The independent replacement remains held and is not included.

## Major changes

**Appearance presets** lives inside **Theme and wallpaper > Backgrounds and overlays**. Restrained dark, Cinematic and Soft ambient coordinate a background and app focus border. Each detail screen requires Apply and offers Save current setup first. Default resets only the preset-managed fields; restoring a previous custom appearance uses its named saved setup. Wallpaper, icons, layout, widgets and motion choices stay saved.

**Contour field and Firefly drift** add optional menu backgrounds and transparent overlays. Existing effects and saved controls remain available. Still and Off retain their existing behavior.

## Minor changes and fixes

Returning from Settings restores the previously selected app, including when an earlier app was hidden. If the selected app was removed, focus moves to a remaining valid position.

Automatic widget text color accounts for the widget surface and full menu background. Explicit colors and opacity remain owner-controlled, including saved opacity when no custom text color is saved.
