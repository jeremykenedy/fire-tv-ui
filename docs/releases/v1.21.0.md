# Fire TV UI 1.21.0

This update adds an optional shared Home row for widget columns and channel cards. The existing separate layout remains the default. The minor version reflects a compatible, optional feature; the independent replacement remains held and is not included.

## Upgrade guide

The direct upgrade source is stable 1.20.1/code 84. The update retains the production package and signing certificate and advances to code 85. Android API 27 remains the minimum. Save a launcher backup and keep selected personal media available before updating.

Use **Settings > Updates > Check for updates** and confirm the Android replacement, or verify the downloaded checksum and install in place:

```sh
shasum -a 256 -c fire-tv-ui-1.21.0.apk.sha256
adb -s YOUR_TV_IP:5555 install -r fire-tv-ui-1.21.0.apk
```

No new permissions, accounts, dependencies, migrations or preference reset are required. Do not uninstall to bypass a signing or version error. Earlier 1.x paths remain in their release guides. The independent preview is not an upgrade source.

After updating, verify that Home retains your existing layout, artwork and card settings. To try the new layout, open **Cards > Featured card setup > Arrange widgets and cards**, then turn **Show widgets and cards together** On. A selected Home card's controls also open the arrangement screen. Move left and Move right position each widget column or feed card. Turn the option Off to return to the separate layout.

Android normally blocks downgrading code 85 to code 84. Keep the installation for a corrective update; a preference backup does not downgrade the APK or restore external media and credentials.

## Breaking changes

None. Mixed mode defaults to Off. Existing widget configuration, separate-layout feed order, card timers, hidden titles and sources, artwork choices and appearance controls are retained. Turning the option On displays widget columns without changing the saved separate Widgets setting.

## Major changes

Widget columns and channel cards can share one horizontal row and one saved order. A widget column retains the original packing of one large widget or two small widgets. Individual widget selection and sizing stay in the existing widget controls. Channel cards retain their current title rotation, controls and provider actions.

The shared order is separate from both the original top-level feed order and the order of titles within a feed. Hidden and unavailable feeds retain their saved shared positions. New positions follow the saved entries. Reset shared order affects only this optional layout. Mode and order choices are included in portable backups and named setups.

## Minor changes and fixes

The arrangement screen identifies widget columns by their contents and retains focus on the moved item. Existing missing-artwork labels, widget text contrast and opaque settings-window backgrounds remain in place. This update does not change logos, add feed providers or alter timer and hiding behavior.
