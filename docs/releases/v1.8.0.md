# Fire TV UI 1.8.0

Reorder the top-level Plex, IPTV and other featured feed cards independently of their individual items. Launcher inactivity now uses the selected screensaver delay.

## Upgrade guide

Replace an existing 1.7.0 or earlier installation with the signed 1.8.0 APK through Updates or the Toolkit. Do not uninstall or clear data. Existing settings and source connections remain on the TV. No new permissions are required. New feed order choices are included in portable backups; connected account credentials remain device-local.

## Breaking changes

None. Existing feed order remains unchanged until you arrange it.

## Major changes

Open the remote Menu on a focused card and choose Arrange top-level cards. Move left or Move right changes the order on Home. The same action is available in Featured card setup. Individual item ordering and hiding remain separate.

## Minor changes and fixes

The launcher uses the current selected screensaver delay instead of a fixed 90 seconds. Disabled delays remain disabled. Returning to Home resets its existing inactivity timestamp, so time spent in settings does not immediately trigger the saver.

## Verification and limits

A signed API 34 native check moved Recently Added before Continue Watching using the remote and verified the changed Home order. Both feeds retained their original first items. The owned fixture and all surrounding preferences, OS values, permissions and external files were restored. Focused ordering and built-smali timer callsite regressions pass. Hardware remote Home interoperability and selected Plex playback after a profile picker remain separate previously documented limits. Extra browser and third-party checker cycles were deferred by the owner.
