# Fire TV UI 1.17.1

This maintenance release repairs the Featured cards switch and individual card dismissal in the existing stable interface. It preserves the 1.x installation and appearance. The separate source preview remains a preview; this repair does not complete the independent replacement.

## Upgrade guide

The verified upgrade path is the production-signed 1.17.0/code 78 installation to 1.17.1/code 79. Android API 27 or newer and the existing production signing certificate are required. Save a backup before updating. No new permissions, accounts, configuration, dependencies or data migration are required.

Use **Settings > Updates > Check for updates**, select Fire TV UI and confirm the normal Android replacement install. Alternatively, verify the downloaded APK and install it in place:

```sh
shasum -a 256 -c fire-tv-ui-1.17.1.apk.sha256
adb -s YOUR_TV_IP:5555 install -r fire-tv-ui-1.17.1.apk
```

Keep the existing installation. Do not uninstall to work around a signature or version error: uninstalling removes private app data. Earlier 1.x versions were not separately exercised for this repair. The source preview uses a different package and is not an upgrade source.

After installation, turn Featured cards Off and return Home, then turn it On again. On a focused card, open Menu and choose **Hide this card**; other items with the same playback link must remain available. Existing per-app Hide Cards settings continue to apply. Saved hidden items remain hidden after a restart.

Android normally blocks an in-place downgrade from code 79. If a problem remains, keep the installation and its data for a corrective update rather than uninstalling. External images and videos must remain accessible separately from the preference backup.

## Breaking changes

None. The runtime minimum, existing settings, default appearance and supported device controls are unchanged.

## Major changes

No new features. This is a focused maintenance repair.

## Minor changes and fixes

- Returning Home reloads the Featured cards visibility setting immediately.
- Card menus retain the identity and title of the selected item, including after hiding and showing cards or rebuilding feed groups.
- Dismissing one item no longer selects another item merely because both use the same playback link.
- Provider rows with an available row identity remain dismissible when optional provider IDs are absent.
- Dismissal remains available after the temporary label cache has been refreshed or evicted.

## Verification and limits

The maintenance suite completed 78 tests: 72 passed and six existing opt-in checks were skipped. Separate checks on Android TV API 34 exercised the actual Off/On and Back flow, per-app Hide Cards checkbox and Save, focused Menu and dismissal, two items sharing a playback link, missing optional provider IDs, and hidden-item persistence after a process restart. Card reconstruction and copying retained the selected item identity and original title.

An actual production-signed 1.17.0 to 1.17.1 replacement preserved all 41 exported test preferences. The installed APK was pulled back and verified byte for byte. The maintenance recipe also passed its hosted build and checks. The exact APK was installed in place on two physical Fire TVs. All 54 and 55 exported preferences respectively, Home routing, accessibility and recorded wake/timer settings matched before and after. Both TVs remained asleep. Physical on-screen card interaction and owner acceptance remain separate from these emulator interaction checks.

Voice power behavior is outside this card repair's verified scope. The independent replacement still requires its own production upgrade and parity qualification.
