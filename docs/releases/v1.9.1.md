# Fire TV UI 1.9.1

Fixes returning from Manual artwork rotation to an automatic interval and refreshes the published Cloud Drift Clock and Blue Meridian previews and release metadata.

## Upgrade guide

Upgrade in place from 1.9.0 through **Preferences > Advanced > Updates**, or download the signed APK and checksum from this release:

```bash
shasum -a 256 -c fire-tv-ui-1.9.1.apk.sha256
python3 scripts/install.py --serial YOUR_TV_IP:5555 --apk /path/to/fire-tv-ui-1.9.1.apk
```

Older Fire TV UI versions can use the same installer. Do not uninstall, clear data or reset the TV. Existing layout, icons, card orders, hidden choices, approved Plex connections and Android settings remain intact. Android 8.1/API 27 remains the minimum. No new dependencies, migrations, account approval or cache reset are required. Save a launcher backup before upgrading. If installation fails, keep the current installation and inspect its stated error. Android may reject downgrades; use a corrective signed update rather than uninstalling.

Screensaver apps update separately. Cloud Drift Clock 2.0.0 is optional and available through Updates or the installation catalog; changing the host catalog does not change the selected screensaver or its app settings. Blue Meridian 1.0.1 is also optional. Its scene combines archival Earth imagery with gentle screen drift, not orbital flight. Cloud's native settings expose playback speed and clock options. Legacy palette and density values remain stored but have no visual effect in the filmed scene.

## Breaking changes

None. This patch retains the runtime floor, fresh-install defaults, existing user preferences and production signer.

## Major changes

- Refresh the Cloud Drift Clock catalog pin to its verified public 2.0.0/code 5 APK and show its real filmed sunset flight, captured on physical Fire TV with the clock off.
- Refresh Blue Meridian to its verified public 1.0.1/code 2 APK and show its actual word-free physical Earth capture, with archival imagery notices.
- Bundle the scene attribution and full CC BY 3.0 license for offline reading under Advanced > Preview media credits.

## Minor changes and fixes

- Changing Big picture artwork from Manual to 5, 8, 15 or 30 seconds now restarts the existing slideshow when returning from settings.
- Preserve the selected source, current card, ordering and focus without recreating Main.
- Show an accurate scene description in the download catalog where one is supplied.

## Security and data

No new permissions or credential storage are introduced. Published app downloads retain checksum, package, signer and version verification. The screensaver selection, device-local equipment identity and approved encrypted Plex profiles are not replaced by catalog updates.

## Verification and known limitations

The rotation regression was reproduced on published 1.9.0. On the API 34 emulator, the fixed production slideshow held Manual artwork for 35 seconds, then resumed through the actual settings picker and Back at a steady 5.004 seconds. The 5, 8, 15 and 30-second choices measured 5.007, 8.014, 14.996 and 30.005 seconds. Selected source and sample cards were retained. This is emulator timing proof, not physical-TV timing proof.

The Cloud and Blue APKs' public digests, byte counts, packages, Android versions and original signers match their tagged integration contracts. Their bundled previews are resized from actual physical API 28 and API 30 captures. Host local checks passed 46 tests with six device-dependent skips; separate native checks are stated explicitly rather than counted as skipped-test passes.

Automatic exact-item Plex handoff and saved-offset resume remain unverified. The attempted external routes opened the installed app's profile picker or Home without an exact playing session. Manual selection of a matching item is not automatic handoff proof. The failed experimental Resume change is excluded from this release. New-episode caption behavior also remains a separate unfinished check.
