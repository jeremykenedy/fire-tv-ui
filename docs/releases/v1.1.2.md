# Fire TV UI 1.1.2

Fire TV UI 1.1.2 makes the TV Sleep Timer directly controllable from **Settings > Screensavers > System timers**. It offers Off and the supported one-time countdowns from 5 minutes through 4 hours, and uses Fire OS's native timer service. The TV Sleep Timer remains separate from the screensaver delay and the Deep Sleep toggle and timer.

## Upgrade guide

Install the signed `fire-tv-ui-1.1.2.apk` from this release over version 1.1.1. The update uses the existing signing key and keeps the current app profile. No settings migration is required. Verify the download with `fire-tv-ui-1.1.2.apk.sha256` before installing.

The Fire TV Toolkit can install the APK and verify its published checksum:

```bash
firetv-ui --install --apk=/path/to/fire-tv-ui-1.1.2.apk --sha256=PUBLISHED_SHA256
```

## Minor changes and fixes

- Added selectable native TV Sleep Timer durations and an Off choice to System timers.
- The timer screen shows the selected countdown's remaining time.
- Kept the TV Sleep Timer independent from screensaver delay and Deep Sleep controls.
- Added the Fire TV Settings package visibility query required to find its native timer service.
- Updated the System timers screenshot and device-control documentation.

## Security and privacy

This release adds no analytics or tracking. The TV Sleep Timer uses the local Fire OS Settings service.

## Rollback

Android does not permit installing the lower version code over this release. To return to 1.1.1, back up the app settings, uninstall 1.1.2, install the signed 1.1.1 APK, then restore the settings.
