# Fire TV UI 1.18.1

1.18.1 repairs two missing controls in the existing production interface. Personal Plex item details now include an individual hide action, and App Icons opens the app growth and shadow controls directly. The independent rewrite remains separate and is not part of this update.

## Upgrade guide

This maintenance update uses the existing production package and signing certificate, advancing 1.18.0/code 80 to 1.18.1/code 81. Android API 27 remains the minimum. Save a launcher backup and keep selected personal media accessible before updating.

Use **Settings > Updates > Check for updates** and confirm the Android replacement, or verify the downloaded checksum and install in place:

```sh
shasum -a 256 -c fire-tv-ui-1.18.1.apk.sha256
adb -s YOUR_TV_IP:5555 install -r fire-tv-ui-1.18.1.apk
```

No new permissions, accounts, dependencies, migration or preference reset are required. Keep the existing installation if Android rejects a signature or version; uninstalling deletes private data. The separate preview is not an upgrade source. Earlier 1.x upgrade paths remain in their versioned guides.

After updating, open a personal Plex card's detail screen and hide one item. Check that another item remains available. Open **UI settings > App Icons > App hover growth and shadow**, choose a growth amount or shadow size, and return Home with Back to inspect the result.

Android normally blocks downgrading code 81 to code 80. Preserve the installation for a corrective update. A preference backup does not downgrade the APK or restore credentials and external media.

## Breaking changes

None. Existing appearance, saved growth and shadow values, app actions and platform requirements are retained. The former shadow toggle in App Icons opens the full growth and shadow controls, including Off. The same controls remain available in Layout and focus.

## Major changes

Personal Plex details offer **Hide this movie**, **Hide this show**, or **Hide this episode** when metadata identifies the item type. **Hide this item** remains available while metadata loads or is unavailable. Hiding targets the exact published item, returns Home and preserves other titles. It does not create a series-wide rule.

**App Icons > App hover growth and shadow** exposes the existing growth choices: Default (18%), Off, 6%, 12%, 24% and 30%. Shadow choices are Off, Default, Large and Extra large. These settings apply to Home and folder apps.

## Minor changes and fixes

Plex details retain **Open item in Plex** and add **Plex feed settings** and the explicit publisher-wide **Hide all cards from Fire TV UI** action. That last action covers all feeds published by the launcher, not only the current Plex feed.

The maintenance builder defaults to 1.18.1 and retains the historical 1.18.0 and 1.17.1 recipes. The default independent build is unchanged.

## Verification and limits

Release qualification is in progress. Native upgrade, screenshots and final publication checks must finish before this candidate is published.

Home routing is unchanged by this repair. A delayed return through Amazon Home remains under investigation on Main; this release does not claim that issue is fixed. Physical remote, voice and receiver acceptance are separate from emulator UI checks. External Plex playback and automatic resume retain their previously documented limitations.
