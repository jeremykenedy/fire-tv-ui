# Fire TV UI 1.4.0

Fire TV UI 1.4.0 adds visible, verified app updates, native Factory UI and Live TV tiles, and portable defaults for fresh installations. It also corrects selected-screensaver idle activation and Home routing from the UI's settings.

## Upgrade guide

Install `fire-tv-ui-1.4.0.apk` over an existing signed 1.x installation. Android 8.1/API 27 remains the minimum; the package and production signer are unchanged. Verify the downloaded APK against its SHA-256 sidecar, save a TV backup, then run:

```bash
shasum -a 256 -c fire-tv-ui-1.4.0.apk.sha256
adb connect YOUR_TV_IP:5555
python3 scripts/install.py --serial YOUR_TV_IP:5555 --apk /path/to/fire-tv-ui-1.4.0.apk
```

The installer replaces the app, retains data, grants the supported one-time setup access and rebinds already enabled Home services. Existing layouts, accounts, app settings, screensaver selections and timers are preserved. No reset, dependency migration or cache clearing is required. Custom layouts remain intact. The separate icon ZIP is optional when the installer already copied the shared icons.

After updating, verify Home from Settings and another app, the selected screensaver, and **Settings > Advanced > Updates**. Keep Android's normal update confirmation enabled. Private UI updates require an authenticated computer handoff through Toolkit; no GitHub token is stored on the TV. See [updates](https://github.com/jeremykenedy/fire-tv-ui/blob/v1.4.0/docs/updates.md).

## Breaking changes

There are no incompatible interfaces or minimum-platform changes. Fresh installs now use the reviewed five-column X Pro layout, 20-minute light standby, deep sleep off and Alexa wake enabled where supported. These defaults do not overwrite existing installations or imported layouts. The explicit simple-setup action uses the same template instead of forcing Never sleep.

## Major changes

- **Check and install updates:** Advanced includes installed catalog screensavers, launchers and IPTV apps. Stable release metadata, exact asset selection, byte count, SHA-256, package identity, installed signer and higher Android version code are checked before Android confirms replacement. Unavailable checks remain unavailable; they never become current-version claims. OwnTV uses the exact versioned TV asset rather than a mobile APK.
- **Private UI handoff:** Toolkit can stage a verified private UI release without copying credentials to the TV. The TV rechecks integrity and the installed signer before confirmation. Fresh metadata expires after six hours.
- **Native TV tiles:** Factory UI opens the actual Amazon system launcher with an intentional temporary bypass. Live TV opens the supported built-in channel guide, not input setup or an IPTV replacement. See [platform behavior](https://github.com/jeremykenedy/fire-tv-ui/blob/v1.4.0/docs/factory-home.md).
- **Portable fresh defaults:** Reviewed layout and bundled Xbox One/Wii U input icons no longer depend on another TV's private file paths. Device-local remote identity, trusted network identity, consent and selected DreamService are excluded.

## Minor changes and fixes

- Launcher idle honors the actual selected DreamService. Android 14 and later uses an exact reviewed app preview when available; unsupported apps retain system idle handling.
- Home from the UI's own settings avoids the Amazon Settings transition grace period.
- Equipment Control recovery is restricted to a previously supported, currently connected remote. Backup imports preserve the destination TV's local identity instead of transplanting another remote's identity. No wireless-debugging approval is included.
- A read-only framework service dump reports sanitized settings-guard state separately from VPN status.
- Add the accepted Prism Clock v1.0.0 as the 31st screensaver catalog entry, with its verified published APK and physical-TV preview. Refresh verified existing Aerial Views, Aquarium 4K, Pipeworks and Twilight release pins without changing the selected app.

## Security and data integrity

Downloads are user initiated. No background update polling or analytics is added. Private UI credentials remain on the computer. APK replacement retains data and rejects wrong packages, changed signers, mismatched hashes, invalid sizes and non-upgrades. The Equipment Control accessibility observer identifies only the exact native error; it does not approve other dialogs. Guard inspection emits no full preferences or raw exception messages.

## Verification and release gates

Local signed build and 29 tests complete: 23 host tests pass and six explicitly configured native tests are skipped. Native Fire OS testing installed the public Fire IPTV v1.1.1 through the UI and Android confirmation, independently verified the installed APK/signer, retained the observable channel catalog and PiP-off setting, and preserved 46 UI preferences and eight OS values. Fresh defaults and existing-install preservation were checked separately on API 34.

Final current-build physical Home, OwnTV, guard-dump and Prism-catalog checks, refreshed screenshots and primary-build artifact verification remain release gates. This document is release preparation, not a publication claim. Third-party checker work is deferred at the user's request.

## Known limitations

Home behavior depends on actual platform accessibility delivery. Shell-injected Home does not exercise Android 11's hardware accessibility input filter. Unsupported or unsigned publisher metadata cannot provide an automatically verified update. Unknown apps retain their publisher/system update path. Display metadata and a bound DreamService do not establish rendered FPS. Physical Android TV/Google TV validation remains welcome; emulator evidence is labelled separately.

## Rollback

Android prevents installing a lower version code over this release. Save a backup before an intentional uninstall, then install the previous signed APK and restore the backup. Uninstalling clears private app data and requires setup again. Independently installed screensavers remain installed. A backup cannot transfer another TV's accounts or device-local remote identity.
