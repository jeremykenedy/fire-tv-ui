# Fire TV UI 1.14.0

Four optional still backgrounds join the existing twelve animations. The screensaver catalog now installs Contour Flow 1.1.0 and Pipeworks 1.1.1 with current native preview images.

## Upgrade guide

Upgrade an existing signed Fire TV UI installation in place. Android API 27 or newer and the same signing key remain required. Use Settings > Updates, Fire TV Toolkit, or download the release APK and its checksum:

```bash
shasum -a 256 -c fire-tv-ui-1.14.0.apk.sha256
python3 scripts/install.py --serial YOUR_TV_IP:5555 --apk /path/to/fire-tv-ui-1.14.0.apk
```

Do not uninstall first. No migration, new credential or cache reset is needed. Saved layout, cards, wallpaper, background styles and controls are preserved. Existing signed 1.x installations can upgrade directly; unsigned or differently signed copies cannot replace them. Back up preferences before recovery work. Android normally rejects a lower version code as an in-place rollback; retain the backup and use a corrective later release rather than uninstalling and losing data. Backups using the new still styles require this version or newer to restore those choices.

The still backgrounds are opt-in under Settings > Theme and wallpaper > Menu backgrounds. Off continues to use your existing wallpaper. Screensaver APK updates remain separate confirmed installations; upgrading the launcher alone does not replace them.

## Breaking changes

None. The runtime floor, existing defaults, wallpaper and twelve animated styles remain unchanged. The previous Animated backgrounds menu label is now Menu backgrounds because it also contains still choices.

## Major changes

- Midnight blue, Warm graphite, Forest dusk and Plum velvet provide still backgrounds behind Home and supported menu panels.
- Still styles keep Intensity and Brightness controls without scheduling animation frames. Speed is shown only for moving styles, and Off hides effect controls without clearing their saved values.
- New still choices are included in portable backups alongside existing styles.

## Minor changes and fixes

- Pin the public Contour Flow 1.1.0/code 6 and Pipeworks 1.1.1/code 3 APKs with verified sizes and SHA-256 values.
- Replace their old catalog thumbnails with native captures from those releases, preserving capture provenance.
- Restore original source SVG bytes referenced by the icon catalog and test all 32 source hashes. Runtime PNG artwork is unchanged.

## Verification and limits

The signed Android build, Java suites and 67 Python cases pass, with seven opt-in native skips in the host suite. Separate Android TV API 34 checks selected all four still styles, compared stable frames, exercised Intensity/Brightness and a native backup round trip, and confirmed that a moving style resumes animation and restores Speed. Off hides unused controls. The exact final signed APK supplied the current native gallery. Original emulator preferences, system settings, permissions, external files and stopped state were restored and checked.

Both screensaver downloads were independently fetched and checked against the catalog. Their own release verification remains separate from launcher validation. This release does not claim new physical Home/Alexa/receiver proof, universal banding-free display output, completion of every screensaver redesign, or acceptance of all existing animations.
