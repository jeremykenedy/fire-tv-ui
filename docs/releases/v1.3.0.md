# Fire TV UI 1.3.0

Fire TV UI 1.3.0 expands the on-TV screensaver catalog with Slot Vision, Hearth Presence, Rain on Glass, Rainforest Cascade, Blue Meridian, and Helios Lightfield. Each app has a sample captured from its running native scene and opens its own configuration screen from Screensaver settings.

## Upgrade guide

Install the signed `fire-tv-ui-1.3.0.apk` over any existing 1.x installation using the same signing key. Android 8.1 / API 27 remains the minimum. Saved layouts, icons, screensaver selection, and timers are preserved. No migration or reset is required.

Verify the downloaded APK against its SHA-256 sidecar. From a checkout of this release, install the APK and its required permissions with:

```bash
python3 scripts/install.py --serial YOUR_TV_IP:5555
```

Open **Settings > Screensavers > Install screensavers**, install the desired app, and return to the picker to select it. Choose **Screensaver settings** for its display options. Existing Pipeworks Dream installations can update in place using the same app signing key. The catalog never changes your selected screensaver automatically.

See [installation and updates](https://github.com/jeremykenedy/fire-tv-ui/blob/v1.3.0/docs/installation.md) and [device controls](https://github.com/jeremykenedy/fire-tv-ui/blob/v1.3.0/docs/device-controls.md).

## Breaking changes

None. Package identity, signing key, runtime minimum, and configuration defaults are unchanged.

## Major changes

- Add Slot Vision, Hearth Presence, Rain on Glass, Rainforest Cascade, Blue Meridian, and Helios Lightfield to the on-TV catalog with pinned signed downloads.
- Refresh the Slot Vision casino and Hearth Presence fireplace previews from their verified native output, and retain app-provided dream settings discovery.
- Add read-only Advanced diagnostics with local device, selection, display, memory/storage and own-app exit information, plus timestamped local reports. Restricted measurements remain unavailable.

## Minor changes and fixes

- Identify unsupported or restricted measurements explicitly; never infer screensaver FPS from display refresh rate or UI frame statistics.

- Extend the settings-route regression check to all six added catalog apps.
- Allow focused settings-route checks through `FIRE_TV_UI_TEST_PACKAGES`; unknown packages fail before system settings are changed.
- Refresh the screensaver preview provenance and release screenshots.

## Verification

The final source builds and passes 38 screensaver checks, 17 input checks, diagnostics parsing checks and 14 Python tests (four device tests require explicit serials and remain skipped in the host run). Actual Google TV API 34 checks cover the new catalog rows and the documented diagnostics route/report save/Back behavior, with secure values preserved. GitGuardian passes. Completed candidate evidence and platform limits are recorded in [the verification guide](https://github.com/jeremykenedy/fire-tv-ui/blob/v1.3.0/docs/verification.md).

## Security and data integrity

Catalog downloads retain HTTPS, exact byte-count and SHA-256 verification, and Android package identity checks. Android confirms installation and removal. This update adds no permissions or network services.

## Rollback

Save a TV backup before uninstalling. Android blocks installing a lower version code over this release. To return to 1.2.0, uninstall 1.3.0, install the signed 1.2.0 APK, and restore the backup. Screensaver apps remain installed independently of Fire TV UI.

## Known limitations

Physical 1.3.0 host installation and remote checks remain coordinated separately; physical Android TV and Google TV have not been checked for this release. Screensaver rendering and available options belong to each installed app. The four older newly catalogued apps remain pinned to their existing published versions; catalog integrity is not a visual quality acceptance. Pipeworks retains its existing pin while its separate replacement is prepared. Prism Clock, Skycast Weather and Horology Drift are not advertised as released downloads.
