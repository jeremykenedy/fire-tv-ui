# Fire TV UI 1.1.3

Fire TV UI 1.1.3 fixes the Settings panel remaining open while Back moves the launcher behind it. Back and Menu dismiss the panel directly, and Home redirection closes menus when returning to Fire TV UI.

## Upgrade guide

Install the signed `fire-tv-ui-1.1.3.apk` over an existing 1.x installation using the same signing key. The update preserves the launcher profile, Home routing, screensaver selection, and timers. No migration or settings reset is needed. Verify the APK against its checksum sidecar before installing.

```bash
firetv-ui --install --apk=/path/to/fire-tv-ui-1.1.3.apk --sha256=7e793de0224699c44bbecd7b177aeff6143620c381454285555ce66eb771627a
```

Press Back or Menu while Settings is open to dismiss it. With Home routing enabled, Home returns to the launcher with menus closed. The gear icon still opens Amazon Settings.

## Breaking changes

None. The Android 8.1 minimum, package identity, signing key, and saved settings remain unchanged.

## Major changes

None.

## Minor changes and fixes

- Consume both key events while dismissing Settings so Back does not move the app grid behind the panel.
- Route Home with the HOME category so the existing launcher menu-reset behavior runs.
- Add device regression checks for repeated Back dismissal, Menu dismissal, Home dismissal, and returning from Theme Mode.
- Refresh release screenshots from the signed build on a physical Fire TV.

## Verification

- Signed APK built, aligned, and verified for v2/v3 signatures.
- 38 Java checks and nine Python checks passed, including remote menu tests on the physical Fire TV. The separate emulator catalog settings-route test was skipped.
- Aquarium 4K activated automatically after idle, rendered moving fish, and exited with Back to the clear launcher. The original five-minute delay and all 45 saved preferences were preserved.
- Captured the final interface and checked its screenshot gallery in a browser.

Verification results are recorded in [the release verification guide](https://github.com/jeremykenedy/fire-tv-ui/blob/v1.1.3/docs/verification.md).

## Security and privacy

No new permissions, network services, analytics, or tracking were added.

## Rollback

Save a TV backup before uninstalling. Android blocks installing a lower version code over this update. To return to 1.1.2, uninstall 1.1.3, install the signed 1.1.2 APK, then restore the saved TV backup.

## Known limitations

The physical device checks cover Fire TV AFTDEC012E on Fire OS / Android 11. Physical Android TV and Google TV devices and a physical reboot were not tested for this patch.
