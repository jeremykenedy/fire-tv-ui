# Fire TV UI 1.17.0

Personalize connected equipment with audio brand artwork, editable input names and individual factory resets.

## Upgrade guide

Update an existing signed 1.x installation in place. Android API 27 or newer and the existing signing certificate remain required.

```bash
shasum -a 256 -c fire-tv-ui-1.17.0.apk.sha256
python3 scripts/install.py --serial YOUR_TV_IP:5555 --apk /path/to/fire-tv-ui-1.17.0.apk
```

Do not uninstall first. Existing names, icons, layout and device controls remain unchanged until a choice is made. The installer copies and indexes the expanded icon pack. The app's native update recovery adds missing icons when storage access is available. No new permissions or account setup are required.

Long press a tile for Change Icon, Use factory icon and Use theme icon. Input tiles also offer Rename input and Use factory name. Input names accept up to 60 characters. Custom names affect the launcher label and preserve the physical port.

Back up preferences before recovery work. Android normally prevents an in-place downgrade from version code 78. Prefer a corrective release instead of uninstalling and losing settings. Older versions do not understand the new input-name and per-tile factory-icon preferences.

## Breaking changes

None. Runtime requirements, global icon-pack choices and existing presentation defaults are unchanged.

## Major changes

* Sixteen audio brands join the 48-image HD pack: Sony, Kenwood, Insignia, Denon, Yamaha, Onkyo, Pioneer, Marantz, Bose, JBL, Sonos, Samsung, LG, Vizio, Harman Kardon and Klipsch.
* Use factory icon restores one tile without disabling the icon pack for other tiles. Use theme icon returns it to the global icon choice.
* Input tiles support custom labels and Use factory name. Renaming preserves the input target, artwork, order and visibility.

## Minor changes and fixes

* The image picker's buried removal action now uses the same factory-icon wording. Wide logos fit completely inside picker thumbnails instead of being cropped.
* Saved setups and portable backups retain input labels and individual factory-icon preferences. Applying a setup without icons preserves current artwork choices.
* The bundled icon installer accepts the expanded manifest while retaining file validation, checksums and preservation of existing user files.

## Verification

Separate Android TV API 34 checks exercised brand selection, individual factory artwork under an active icon pack, theme restoration and full-width picker previews. Physical Fire TV checks exercised input renaming and the scrolling input menu. Final combined-build verification is recorded in the device verification guide.
