# Fire TV UI 1.16.0

Save named UI setups, add transparent animation over your own wallpaper, and give each channel card its own rotation timer. Channel management now lives under Cards as **Channel Cards**.

## Upgrade guide

Update an existing signed 1.x installation in place. Android API 27 or newer and the same signing certificate remain required. Download the APK and its checksum, then use the repository installer:

```bash
shasum -a 256 -c fire-tv-ui-1.16.0.apk.sha256
python3 scripts/install.py --serial YOUR_TV_IP:5555 --apk /path/to/fire-tv-ui-1.16.0.apk
```

Do not uninstall first. No new permission, account connection, migration or cache reset is required. Existing settings and the eight-second default card interval remain unchanged. Screensaver APK updates remain separate installations.

- Open **Theme and wallpaper > Backgrounds and overlays** for independent full backgrounds and transparent overlays.
- Open **Theme and wallpaper > Saved setups** to save, apply, rename, update or delete a named UI setup.
- Open **UI settings > Cards > Channel Cards** for the existing channel and individual-item controls.
- Open **UI settings > Cards > Card timers** for global and per-channel intervals. An individual card can inherit the global timer, use custom whole seconds, or stay on Manual.

Back up preferences before recovery work. Android normally rejects an in-place downgrade from version code 77; use a later corrective release instead of uninstalling and losing settings. Older releases do not understand the new overlay and per-channel timer choices. Named setups are local to this installation and are not included in the existing portable preference backup.

## Breaking changes

None. Existing defaults, wallpaper, account connections, TV power controls and runtime requirements stay unchanged. **Menu backgrounds** is now labeled **Backgrounds and overlays**. **Channel Manager** has moved under Cards and is labeled **Channel Cards**.

## Major changes

- Independent background and overlay layers preserve the current wallpaper. Existing styles can be used as overlays, alongside falling snow, snowflakes, leaves, falling hearts, floating hearts, petals and floating lights. Each layer supports still/off choices and its own controls.
- Forty-one holiday, seasonal and celebration palettes include multiple religious traditions and secular occasions. Optional icon colors are separate from the background choice. This is a curated selection, not an exhaustive list of every holiday; saved setups support additional personal combinations.
- Named setups preserve presentation, layout, app arrangement, card order and timers. Custom still wallpaper and icon images are copied into private storage. Video wallpaper sources are saved as references and must remain accessible. Applying a setup can retain current icons; account authorization and TV hardware controls are excluded.
- Stable channel identities now have independent rotation deadlines. Changing one channel's timer does not move the card strip or reset unrelated channel deadlines.

## Minor changes and fixes

- Pin verified Black Screen 1.0.1/code 2, which requests minimum brightness in its preview and actual screensaver window. Updating that saver remains a separate installation.
- Channel Cards handles the complete Back gesture before the underlying settings page, preserves cancelled changes, and restores focus after Back or Save.
- Cards opens with focus on its first control, and Card timers is directly reachable from the same menu.
- Backup validation rejects malformed or duplicate channel timer overrides and invalid overlay settings without partially restoring them.
- Hidden and paused menu animation stops scheduling frames. Static overlays retain their composition without continuous drawing.

## Verification and limits

The combined signed Android build and 73 host tests passed, with six opt-in native checks skipped in the host run. Separate native Fire TV checks exercised all seven new overlay motifs, real custom wallpaper composition, Still and Off, card navigation, independent real-provider title changes, and timer settings. Saved-setup tests covered copied images after their original files were removed, optional icon preservation, layout and timer restoration, rename/update/delete, invalid names, and Back/focus behavior.

On an integrated Fire TV running API 30, controlled Home samples measured about 59.8 frames per second for snowflakes and connected lights, with approximately 1.0 to 1.4 percent reported jank after warmup. The existing Compose Cards settings popup has higher compositing latency with a moving overlay: a measured sample had a 38 ms 95th-percentile frame duration and 24 deadline misses in 584 frames. These are bounded device measurements, not a guarantee for every TV or combination of layers. Still and Off remain available.

This release does not establish a fix for physical receiver or soundbar power behavior, Alexa association, or every outstanding screensaver visual request. Saved setups do not transfer Plex users or credentials, TV power settings, or settings inside other apps.
