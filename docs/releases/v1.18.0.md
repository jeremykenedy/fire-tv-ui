# Fire TV UI 1.18.0

1.18.0 makes the stable card controls available through Select and Menu, adds optional app focus growth and shadow sizes, and removes the empty card band when cards and widgets are disabled. It retains the existing 1.x interface. The independent source-native candidate remains separate and is not a qualified replacement.

## Upgrade guide

The verified direct upgrade path is production-signed 1.17.1/code 79 to 1.18.0/code 80. Android API 27 or newer and the existing production signing certificate are required. Save a launcher backup and retain accessible copies of selected personal media before updating.

No new permissions, accounts, dependencies, configuration changes or data migration are required. Existing layout, source visibility, title hides, focus styling and disabled-shadow choices remain in place unless you change them. New growth and shadow preferences are validated and included in supported backups and saved setups.

Use **Settings > Updates > Check for updates**, choose Fire TV UI and confirm the normal Android replacement. Alternatively, verify the released APK and install it in place:

```sh
shasum -a 256 -c fire-tv-ui-1.18.0.apk.sha256
adb -s YOUR_TV_IP:5555 install -r fire-tv-ui-1.18.0.apk
```

Keep the existing installation. Do not uninstall to bypass a signature or version error; uninstalling deletes private app data. Earlier 1.x versions were not separately exercised for this release. The preview package is separate and is not an upgrade source.

After installation:

1. Select a Home card and check that its current title heads a menu containing Open and the available hide actions. Open should run the original provider action only when selected.
2. Hide one title and confirm that another title with the same playback link remains available. Use Hidden cards to restore it.
3. Check the separate **Hide all cards from &lt;app&gt;** source choice. It covers every feed published by that app while keeping its app tile. Re-enable the source in Featured card setup and choose **Reload home cards** when needed.
4. Turn cards Off with widgets disabled and check that the empty band closes. Enabled widgets must retain their row.
5. Open **UI settings > Layout and focus**, choose growth and shadow sizes, and return with Back to check the focused app tile. Confirm the saved choices after restarting Home.

Android normally blocks an in-place downgrade from code 80 to code 79. Keep the installation and its data for a corrective update. A preference backup restores supported settings on a compatible version; it does not downgrade the APK or restore account credentials and external media.

## Breaking changes

The runtime floor, permissions and default appearance are unchanged. The card's normal Select action now opens controls instead of immediately taking its original provider action; choose **Open** to perform that same action. Remote Menu and Enter reach those controls too.

The existing 18% growth and 18 dp shadow remain the defaults. A previously disabled shadow remains disabled. No mandatory setup or migration step is introduced.

## Major changes

### Visible card controls

Select or press Menu on a card to see its exact current title and available actions. **Open** preserves the original provider action. **Hide this title** uses the carried exact item identity, preserving distinct titles that share a playback link. Open remains available if title identity is unavailable. The old `Menu: Card options` suffix is removed.

**Hide all cards from &lt;app&gt;** uses the existing publishing-app visibility setting. It covers that app's other channels and Watch Next feeds and leaves the app tile visible. It does not create a single-channel, movie, show or series hide rule. Personal Plex recommendations published by Fire TV UI share that publishing source with its other owned feeds.

### App focus sizes

**UI settings > Layout and focus** adds these optional choices:

| Control | Choices |
| --- | --- |
| App focus growth | Default (18%), Off, 6%, 12%, 24%, 30% |
| App focus shadow | Off, Default (18 dp), Large (28 dp), Extra large (38 dp) |

Growth and shadow changes refresh on return with Back, including the same previously rendered app tile. Focus fill, border styling and original artwork remain independent. Defaults preserve the existing appearance.

## Minor changes and fixes

- Hiding cards collapses their reserved Home band when widgets are disabled. Enabled widgets retain their row.
- Card setup guidance describes Select and Menu and distinguishes hiding the current title from hiding all feeds from a publisher.
- Source hiding preserves other app visibility entries and metadata, verifies its saved value, and restores the prior preference if the write fails. Restoring a source refreshes Home immediately on return, without restarting the app.
- Backup and saved-setup validation accepts the new bounded focus preferences.
- The maintenance recipe defaults to 1.18.0; `--version 1.17.1` retains the historical repair build. The default source-native candidate build remains separate.

Fourteen source-native production contract checks passed for its separately reserved version code.

Android TV API 34 checks exercised Select and Menu, the exact original provider Open action, shared-link and row-only title hiding, persistence after restart, and publisher-wide hiding while preserving 24 sibling publisher settings. The final restore and Reload flow retained the same process and restored all 25 publisher objects exactly. Cards-off spacing was checked with six and seven columns in ordinary and mini layouts. With widgets enabled, all four layout combinations retained visible apps and widgets, supported Up/Down navigation, and opened the Add widget chooser with Select and returned with Back.

Actual settings controls changed Home and folder growth through Off, default and 30%, and shadow through Off, default, Large and Extra large. Same-first-app Home changes applied without a process restart. Largest folder artwork remained visible inside its panel. The final production-signed APK also passed a direct 1.17.1 replacement: all 21 sampled exported settings and canonical backup bytes were preserved through startup and process restart. These are supported preference checks, not a claim that every private file or external service was exercised.
