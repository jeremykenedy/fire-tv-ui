# Fire TV UI 1.13.0

This release organizes settings around their purpose, makes every installed screensaver configurable without selecting it, and adds custom card timing, app columns and focus colors.

## Upgrade guide

Upgrade an existing signed Fire TV UI installation with the release APK and its SHA-256 file. Android API 27 or newer remains required. Use Settings > Updates, Fire TV Toolkit, or the repository installer:

```bash
shasum -a 256 -c fire-tv-ui-1.13.0.apk.sha256
python3 scripts/install.py --serial YOUR_TV_IP:5555 --apk /path/to/fire-tv-ui-1.13.0.apk
```

Do not uninstall first. Replacement preserves app data, saved layout, cards, backgrounds and screensaver choices. No schema migration or new credential is required. Open Settings > Updates to check shared icon access and add missing files; existing images are preserved. Back up preferences before any manual recovery. Android generally rejects a lower version-code APK as an in-place rollback; keep the backup and use a later corrective release rather than uninstalling and losing data.

## Breaking changes

None. Existing preferences and defaults are preserved. Display labels and settings locations change: Appearance is UI settings, Theme Mode is Theme and wallpaper, and app columns are under UI settings > Layout and focus. Screensavers has its own dedicated entry.

## Major changes

- Configure, Preview and Set active sit beside each saver, with active labeling and return-position restoration.
- Card rotation accepts custom whole seconds from 1 to 86400, alongside existing presets and Manual.
- Layout and focus offers more app-column presets, custom 2-12 columns, Default, Border only and Color and border focus styles, plus preset or custom RGB colors.
- Updates shows installed/available versions, progress and retry without rebuilding the whole list. The APK bundles shared icons and copies only missing files when storage access permits.

## Minor changes and fixes

- Ordinary Home delivery keeps the existing activity instead of unconditionally recreating it. A focused transient popup retains the compatibility reset needed to dismiss it.
- Transparent icon-pack artwork remains readable against a focused tile without recoloring the image.
- Catalog return performs one refresh so installer return does not discard the saved scroll position.
- Pixel-identical static SVG optimizations preserve the rendered artwork and hashed animated banners.

## Verification and limits

The signed Android build and local behavior checks pass. Native verification and release screenshots are being completed before publication. Hardware Home routing, Alexa and receiver behavior are separate device concerns; this release does not claim to resolve those unverified paths. Horizontal app scrolling, row limits, additional icon packs and screensaver visual reworks are not part of this release.
