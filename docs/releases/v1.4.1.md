# Fire TV UI 1.4.1

Fire TV UI 1.4.1 corrects update checks for Home Redirect and strictly selects OwnTV's versioned TV APK. It also gives the built-in Live TV and Factory UI tiles dedicated artwork and corrects the fresh-install TV tile order. Upgrades preserve app data, timers, screensaver selection and custom icons.

## Upgrade guide

Upgrade an existing signed 1.4.0 installation through Toolkit's authenticated private UI handoff, then confirm the replacement in **Settings > Advanced > Updates**. The repository and APK remain private; no GitHub credential is sent to the TV. Verify `fire-tv-ui-1.4.1.apk` against its SHA-256 sidecar before a computer-managed installation. Android 8.1/API 27, package identity and the production signer are unchanged.

No reset, migrations, dependency installation, cache clearing or preference import is required. Earlier signed 1.x installations can use the existing computer installer; versions without the Updates receiver need that bootstrap path. Save a backup before updating. After replacement, check the installed app version, Home, the selected screensaver and the Updates screen.

## Breaking changes

None. Existing settings keys and supported platforms are unchanged. OwnTV checks reject an APK whose name does not match the checked tag, even when it is the release's only APK. Unavailable checks remain unavailable.

## Major changes

Home Redirect now checks published release history for its exact Android artifact when the latest Toolkit desktop release has no helper APK. It verifies the APK's package, checksum and installed signer and compares the compiled Android version code. The screen shows the actual app version separately from the repository tag, preventing Toolkit's version number from creating a false app update.

## Minor changes and fixes

- Select the newest publication containing the exact helper APK within the first 100 release-history entries; skip drafts and prereleases.
- Reject cached OwnTV metadata whose artifact name does not match its checked tag.
- Preserve the existing single-APK compatibility path for ordinary, untemplated publishers.
- Remove the temporary helper APK after read-only version inspection. Installation still requires a higher Android version code and Android's normal confirmation.

- Native TV tiles use original bundled artwork when no custom icon exists. The fallback is loaded through the existing image pipeline without writing icon preferences; a user-selected image always wins.
- Fresh installs use the accepted five-column app order with Live TV beside OwnTV. Existing installations retain their saved order; the launcher can reorder the tile without resetting other settings.

## Security and data integrity

Existing download size, SHA-256, package and signer verification remain mandatory. Failed metadata or APK inspection does not leave an install action enabled. No new permissions, background checks, accounts or device configuration changes are introduced.

## Verification

Local source and signed APK build pass. All 30 tests completed: 24 passed and six native opt-in checks were skipped. Focused regressions cover desktop-only newest releases, unrelated APKs, publication order, drafts, prereleases, the history bound, missing OwnTV artifacts, cache filename validation and actual Android version-code comparisons. Preliminary code 39 physical testing of `153da5a2` shows Home Redirect app 1.2.6 (code 10), repository tag v3.9.1, its checked checksum and a disabled Matches checked release action. OwnTV 5.2.1 also matched its exact published TV APK. All 46 portable UI preferences and nine OS settings read back unchanged; external backup/import files, the live settings guard and VPN were preserved. The preliminary Factory UI tile opened Amazon Home afterward. Final code 40 (`ca1b8b5a`) displayed the dedicated Live TV glyph on the first page, opened the actual native channel guide, and returned to Main through Back and injected Home. A fresh comparison preserved the current 46 preferences, nine OS values, byte-exact external backup/import files, live guard and VPN. The guide showed schedules loading; this proves routing rather than channel playback. The published private 1.4.0-to-1.4.1 handoff remains a separate post-publication gate. Third-party checker work remains deferred at the user's request.

## Known limitations and rollback

Release history inspection is bounded to 100 entries and requires accessible verified publisher metadata. A network or integrity failure is unavailable, never an up-to-date claim. The API 34 Google TV image blocked a first installation of the existing Home Redirect helper with a Play Protect older-platform warning. That installation was cancelled without bypassing security; the helper row was verified on Fire OS with the already installed helper instead. Emulator UI preferences, nine OS settings, three screensaver exports, stopped guard and storage appop were restored. The physical remote Home limitation documented for 1.4.0 is unchanged. No new screensaver visual quality claim is made.

Android does not permit an in-place downgrade to a lower version code. Retain a backup before any intentional uninstall and restore it after reinstalling the previous signed version; uninstalling clears the UI's private app data. Independently installed screensavers remain installed.
