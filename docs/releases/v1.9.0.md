# Fire TV UI 1.9.0

Adds separately authorized Plex Home Continue Watching feeds, working URI artwork for supported app recommendations on Android 9, and direct public self-update checks.

## Upgrade guide

From 1.8.0, check **Preferences > Advanced > Updates**, or use the published signed APK with the existing installer:

```bash
shasum -a 256 -c fire-tv-ui-1.9.0.apk.sha256
python3 scripts/install.py --serial YOUR_TV_IP:5555 --apk /path/to/fire-tv-ui-1.9.0.apk
```

Older Fire TV UI versions can use the same in-place installer with the production signing key. Do not uninstall or clear data. Existing launcher preferences, approved Plex connections and Android settings are retained. New Plex Home profiles are optional: open Featured card setup > Connect your own Plex library > Library feeds and activity users > Other users' Continue Watching. Protected profiles need their own PIN.

No new dependencies, account approval for existing owner connections, migrations or cache resets are required. Android 8.1/API 27 remains the minimum. Save a launcher backup before upgrading. If installation fails, retain the current app and inspect the stated error. Android may reject a downgrade; preserve the backup and prefer a newer corrective signed release over uninstalling.

## Breaking changes

None for existing installations. Fresh installations now start with the owner-reviewed six-column Electric Indigo layout. Existing and imported layouts are preserved. No selected DreamService, device-local equipment identity, personal credentials or hidden-card choices are added to the fresh defaults.

## Major changes

- Add one or more separately authorized Plex Home profiles, each with its own real Continue Watching feed. The owner connection stays intact; activity history is not relabeled as another user's Continue Watching.
- Resolve real server account names in activity-user filters. New movies, new episodes, currently playing and recently watched remain separate choices.
- Check the public Fire TV UI release directly using its exact versioned APK and compiled Android version. Authenticated computer staging remains a fallback for private or inaccessible sources. Errors and rate limits never become current-version claims.

## Minor changes and fixes

- Load normally authorized same-producer content artwork and reviewed Tubi HTTPS images with bounded bytes and image dimensions. Original producer actions and their identity checks remain unchanged.
- Follow reviewed public Plex artwork CDN redirects without forwarding server credentials.
- Read bundled preview-media attribution and complete licenses offline from Advanced.
- Correct the Black Screen preview index to match its actual DreamService component.

## Security and data

Profile credentials remain encrypted on the TV and excluded from portable backups. Profile identity and exact server identity are verified before saving a credential. No profile PIN is reused across users. Downloaded app updates retain package, published checksum, current signer and higher-version checks before normal Android confirmation.

## Verification and known limitations

The original Fire TV authorized an unprotected managed profile and published its separate real feed. Owner and managed-profile Continue Watching each returned 12 items with no overlap. After the card URI opened Plex's profile picker, selecting the managed profile returned Plex Home. The matching Continue Watching item was then opened and played manually; an authorized server session query confirmed that exact item and playing state. This does not establish automatic card-to-item handoff. External Plex Resume still encounters the installed app's household picker and did not establish automatic offset playback. A picker or generic Plex launch is not playback proof.

Physical Android 9 output verified Tubi HTTPS and Netflix content-provider artwork, plus the original Netflix action. The API 34 sample profile controls and full offline credits were captured with safe data. Local verification passed 45 tests, with six device-only skips. The final public self-update screen verified the previous stable 1.8.0/code 53 APK and correctly disabled replacement of the newer 1.9.0 build.
