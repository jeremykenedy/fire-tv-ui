# Fire TV UI 1.9.0

Adds separately authorized Plex Home Continue Watching feeds, server account names in activity filters, offline preview media credits, and bounded URI artwork for supported app recommendations.

Existing owner connections and launcher preferences are retained. Adding a protected Plex Home profile requires that profile's own PIN. Credentials remain encrypted on the TV and are excluded from portable backups. Activity history is not relabeled as another profile's Continue Watching.

Plex artwork may follow reviewed public Plex CDN redirects without forwarding server credentials. Recommendation artwork uses normal same-producer content-provider access or the reviewed Tubi HTTPS image host; downloads and decoded dimensions are limited. Original producer actions and their identity checks remain unchanged.

Fresh installations use the reviewed six-column Electric Indigo layout. Existing and imported layouts are preserved. The Black Screen bundled preview index now matches its actual DreamService component.

## Verification

The original Fire TV authorized an unprotected managed profile, published its separate real feed and played the matching selected episode. Server-side session evidence confirmed the exact item and profile. The sample profile controls and full offline credits were captured on the API 34 TV emulator. Physical Android9 output verified Tubi HTTPS and Netflix content-provider artwork, plus the original Netflix action. The household profile picker remains a separate limitation for automatic external Plex Resume; matching-title playback was verified after native profile/item selection.

Use the signed private release APK and matching checksum. Upgrade in place with the existing production signer; do not uninstall or clear app data.
