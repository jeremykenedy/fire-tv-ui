# Featured cards

Featured cards show recommendations published by installed apps. Enable them at **Preferences > Appearance > Cards** by turning **Hide featured cards** off. This preference controls visibility; it does not create a feed.

Open **Card sources and refresh** from that same page to see which apps have published cards. **Refresh sources** reads the current feeds. **Reload home cards** returns to the launcher and requests its normal reload. A source that cannot be read is shown as unavailable, rather than reported as an empty or working feed.

The screen distinguishes featured cards, Continue Watching, and live TV/app channels. Live TV channels alone do not prove that an app has published recommendation cards. Source names come from installed app labels. Fire IPTV can publish real starter/live recommendations through its separate supported app release.

Amazon Home uses a separate recommendations service. This launcher reads Android TV app-published cards; installing Prime Video, Netflix, or Plex does not guarantee those apps publish compatible cards. A direct connection to a personal Plex library is ongoing work and is not included in 1.5.0.

The card subtitle identifies its actual source. Artwork fits inside the existing card background while preserving proportions, so wide logos and portrait posters are not cropped into oversized fragments. Existing visibility controls, app order, custom icons, and widget settings remain unchanged.
