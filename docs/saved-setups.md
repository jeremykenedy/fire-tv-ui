# Saved setups

Open **Settings > Theme and wallpaper > Saved setups** to keep named versions of your current Fire TV UI appearance and layout.

Choose **Save current setup**, enter a name, and save. Select a saved setup to apply it, rename it, replace it with your current setup, or delete it. Applying a setup replaces the current presentation settings, so save the current setup first if you want to return to it. You can leave **Apply saved icons too** unchecked to keep the current icon pack and custom tile images.

## What is saved

| Area | Included settings |
| --- | --- |
| Appearance | Theme, wallpaper, colors, backgrounds, overlays and animation controls |
| Layout | App order and visibility, folders, columns, scrolling, row limits and focus styles |
| Cards | Channel visibility, item and feed order, hidden items, artwork fit and global/per-channel timers |
| Widgets | Widget configuration, status bar presentation, clock and weather display choices |
| Icons | Selected icon pack and copied custom tile images, applied optionally |

Custom wallpaper and icon images are copied into private app storage. Installed icon packs still need to remain installed. Up to 24 setups are supported, with 96 MB of copied images in total and a 20 MB limit per image. Names can contain 1 to 60 characters and must be unique.

## What stays unchanged

TV power, sleep timers, screensaver selection, Home protection, account connections, Plex authorization and settings inside other apps are unchanged. Applying a setup does not switch a Plex household user or enable Android notification permissions.

Saved setups are local to this Fire TV UI installation. They are not included in the existing portable preference backup. Clearing Fire TV UI app data or uninstalling the app removes the setup library and its copied images. Ordinary app updates preserve it.

Deleting a saved setup leaves the current appearance in place. A copied image that is still used by the current setup is retained. Unavailable images and invalid saved data produce an error instead of partially replacing the current settings.
